I built this agent to answer support tickets using a supplied knowledge base.
The project covers three support ecosystems, with 117 documents and 29 tickets.
It runs without looking up additional information on the web.

## Retrieval and answers

The retriever combines sentence embeddings with BM25 keyword matching. Retrieved
passages provide the material for the answer, and grounding checks restrict it to
that material.

I added forbidden-pattern filtering and checks after generation. When the answer
doesn't meet the grounding requirements, the pipeline follows an explicit escalation
path. Retrieval, generation, and validation are separate modules.

## What the evaluation covers

The 29-ticket set exercises the pipeline on the supplied scenarios. It is a small
project evaluation, rather than evidence of performance across a live support queue.
The code and setup are available in the repository.
