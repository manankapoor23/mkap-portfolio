## Overview

A retrieval-augmented agent that triages support requests against a fixed knowledge
base — grounded, auditable, and closed-book to the outside world.

## The problem

Support answers have to be traceable. A model that free-associates or reaches for
the open web is a liability. The goal was an agent that answers *only* from an
approved corpus, and escalates predictably when it can't.

## Retrieval

Hybrid **dense + BM25** retrieval over a 117-document corpus, so both semantic and
exact-keyword matches surface. Answers are hard-grounded in retrieved passages —
**zero external lookups**.

## Guardrails

```
retrieve  →  ground  →  generate  →  filter  →  escalate
```

- Forbidden-pattern filtering on inputs and outputs
- Post-generation guardrails before anything is returned
- Deterministic escalation when confidence or grounding is insufficient

## Pipeline

The system is structured as a **16-module pipeline** — retrieval, grounding,
generation, and safety are separate, testable stages rather than one prompt.

## Results

Evaluated on **29 real support tickets**, the agent stays grounded and escalates
deterministically instead of guessing.
