This project connects a Slack question to a database query. A user sends
`/ask-data`, the model generates SQL using the database schema, and the bot posts
the result back in Slack.

## How it works

Slack Bolt handles the command. LangChain passes the question, schema, and sample
rows to Gemini 2.0 Flash. The generated query runs against SQLite, and the result
is formatted for the channel.

The pipeline strips Markdown fences, checks for SELECT queries, and caps returned
rows. Those checks help constrain execution, but a query still needs to match the
user's question: successfully running SQL doesn't by itself mean the answer is right.
