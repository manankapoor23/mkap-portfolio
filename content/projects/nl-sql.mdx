## Overview

A Slack-native data assistant: run `/ask-data` in plain English, get an answer from
the database — no SQL, no leaving the channel.

## The problem

The people with questions about the data usually aren't the people who write SQL.
The round-trip through an analyst is slow. NL → SQL closes that gap where the
questions already happen: in Slack.

## How it works

```
/ask-data slash command (Slack Bolt, socket mode)
      ↓
schema-aware prompt (LangChain + Gemini 2.0 Flash, temp 0)
      ↓
generated SQLite SELECT
      ↓
SELECT-only guardrail + markdown-fence strip + row cap
      ↓
formatted result block in-channel
```

Built with LangChain orchestrating Gemini 2.0 Flash, the assistant generates
**schema-aware SQL** grounded on an in-prompt table schema with sample rows, run at
**temperature 0** for determinism.

## Notes

A **SELECT-only guardrail** rejects all DDL/DML before execution, alongside
markdown-fence stripping and a row cap — keeping the model schema-aware is what
makes the SQL executable rather than plausible.
