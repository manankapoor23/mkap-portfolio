Rimshot brings Touch Bar-style controls to a MacBook trackpad. Rest a finger on the
top edge and an on-screen strip appears. Slide to select a control, then lift to
activate it. It supports brightness, volume, keyboard backlight, media, screenshots,
and Mission Control.

## What I built

The app is written in Swift and AppKit. It watches trackpad contact, maps movement
to controls, and uses haptic feedback as the selection changes. Holding on a control
can turn it into a slider, while sliding away cancels the action.

It includes a trackpad view for seeing the active zones and a menu bar interface for
settings. The project has a downloadable macOS release and a published build guide.
